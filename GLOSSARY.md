# Glossary

Terms of **truely-godot-engine** (this fork of [godotengine/godot](https://github.com/godotengine/godot)) and the Godot terms they build on, with main source files, issues and [wiki](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki) pages. A **file index** by feature area follows the terms.

- Rules: [`AGENTS.md`](AGENTS.md), [`truely/CONVENTIONS.md`](truely/CONVENTIONS.md), [`truely/FEATURE-WORKFLOW.md`](truely/FEATURE-WORKFLOW.md), [`truely/README.md`](truely/README.md). Order and dependencies of the work: tracker issue #32.
- A new public term, class or setting gets an entry here (alphabetical, 1 to 3 sentences, paths, issues, wiki page).
- Paths use `name.*` for the `.h` and `.cpp` pair.

## Terms

### A

**Abnahme checks** (acceptance checks): the five fixed points that end every feature and refactoring issue: C++ API, bindings, docs (class reference and wiki), test build, GDScript and C# test in the test project. Ticked in the issue; results go in as a comment. See `truely/CONVENTIONS.md` (section 3) and `truely/FEATURE-WORKFLOW.md` (section 6).

**AccessibilitySettings** / **AccessibilitySettingsServer**: settings domain for accessibility options; `AccessibilityColorScheme` is its color resource. In code: `servers/settings/accessibility_*.*`. Wiki: [`Accessibility-Settings`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Accessibility-Settings), [`Class-AccessibilitySettingsServer`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Class-AccessibilitySettingsServer).

**AudioBusSettings** / **AudioBusSettingsServer**: settings domain that stores and applies volume and mute of the audio buses. In code: `servers/settings/audio_bus_settings_server.*`, `servers/settings/audio_settings.*`. Wiki: [`Audio-Bus-Settings`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Audio-Bus-Settings).

**AudioCommand** / **AudioCommands**: data description of an audio action (and a collection of them) that can be stored, edited in the inspector and run later. `AudioCommands` was `AudioCommandList` before 0.2.2 (deprecated name, old `.tres` files still load). In code: `scene/audio/audio_command.*`. Wiki: [`Audio-Commands`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Audio-Commands).

**AudioDeviceSettings** / **AudioDeviceSettingsServer**: settings domain for the output and input audio device. In code: `servers/settings/audio_device_settings_server.*`. Wiki: [`Audio-Device-Settings`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Audio-Device-Settings).

**Audio fade** (`AudioFade`): one gain or volume fade over time with a curve (`AudioMixerServer.FadeCurve`), shared by `AudioMixerServer` and the `AudioStreamPlayer` nodes. Applied once per frame through the playback volume; `AudioServer` ramps it per mix block, so it does not click. In code: `scene/audio/audio_fade.h`. Issues: #74, #362.

**AudioMixerServer**: C++ singleton that manages named audio channels (`AudioMixerChannel`) and a layout (`AudioMixerLayout`) on top of the audio buses. It lives in `scene/audio/` (not `servers/`) because `AudioStream` lives in `scene/`. In code: `scene/audio/audio_mixer_server.*`, `scene/resources/audio/audio_mixer_*.*`. Issues: #13. Wiki: [`Audio-Mixer`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Audio-Mixer), [`Design-Decisions`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Design-Decisions). Not to confuse with `AudioServer` (Godot's bus server) or `AudioBusSettingsServer` (saved player settings).

**AudioStreamPlayer fades and track info**: `fade_in()`, `fade_out()`, `crossfade_to()`, fade gain, track info (`get_current_track_index()`, `get_track_position()`, `get_position_in_playlist()`) and the signals `stream_changed`, `track_changed`, `fade_finished`, `position_changed` (opt-in, `position_signal_interval`) on `AudioStreamPlayer`, `AudioStreamPlayer2D` and `AudioStreamPlayer3D`, shared through `AudioStreamPlayerInternal`. Use it for a node in a scene; use `AudioMixerServer` channels for global music with queues and ducking. In code: `scene/audio/audio_stream_player_internal.*`. Issue: #362. Wiki: [`362-feature-audio-player-fades-playlist`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/362-feature-audio-player-fades-playlist).

**AudioStreamPlaylist list API**: typed `streams` list (old `stream_count`/`stream_N` still load), `add_stream()`, `insert_stream()`, `remove_stream()`, `move_stream()`, `find_stream()`, `get_stream_name()`, time helpers `get_stream_length()`, `get_stream_start_time()`, `get_stream_index_at()`, and the current track of `AudioStreamPlaybackPlaylist`; inspector list with move up/down. In code: `modules/interactive_music/audio_stream_playlist.*`, `modules/interactive_music/editor/audio_stream_playlist_editor_plugin.*`. Issue: #362.

**AudioStream track information**: fields directly on every `AudioStream` (groups Track, Release, Artwork, Notes: `title`, `artist`, `album`, `album_artist`, `track_number`, `track_count`, `disc_number`, `disc_count`, `year`, `genre`, `composer`, `copyright`, `cover` (decoded lazily from `cover_data`), `comment`), format getters `get_sample_rate()`, `get_channel_count()`, `get_bitrate()`, `get_codec()`, and `AudioStream.load_info(path)` (fields and format without audio data, for library lists). Read from ID3v2/ID3v1 (MP3, WAV `id3 ` chunk), RIFF LIST/INFO (WAV) and Vorbis comments (Ogg Vorbis, Opus) by all loaders (`audio/info/read_file_tags`) and importers (import option group `info/` with overrides). Not to confuse with `AudioStreamPlayback::TrackInfo` (current track of a playlist, #362). In code: `scene/resources/audio/audio_stream.*`, `scene/resources/audio/audio_stream_tags.*`. Issue: #363. Wiki: [`363-feature-audio-stream-track-info`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/363-feature-audio-stream-track-info).

### B

**Batch CI** (CI in batches): the full CI of all platforms runs only on pushes to `truely-godot-engine-releases` (about once per 8 to 10 merged features), not on feature branches or `truely-godot-engine`. Feature branches are checked locally (Windows, Mono, unit tests, GDScript and C# checks); manual run: `gh workflow run runner.yml --ref <branch>`. In code: `.github/workflows/runner.yml`. Issues: #46, #273. See `truely/FEATURE-WORKFLOW.md` (2.4).

**Bindings**: registration of a C++ class for scripts in `_bind_methods()` (`ClassDB::bind_method`, `ADD_PROPERTY`, `ADD_SIGNAL`, `BIND_ENUM_CONSTANT`). In this fork the C++ object is the API: GDScript sees it directly, C# through the generated glue. See `truely/CONVENTIONS.md` (1.1).

### C

**Cached resource paths**: `ResourceLoader` lists the paths of all resources currently in the resource cache, filtered by type, extension or folder. In code: `core/io/resource_loader.*`. Wiki: [`Cached-Resource-Paths`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Cached-Resource-Paths).

**Camera3DSettings** / **Camera3DSettingsServer**: settings domain for 3D camera options. In code: `servers/settings/camera_3d_settings*.*`. Wiki: [`Camera-3D-Settings`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Camera-3D-Settings).

**Children of a type**: find all descendants of a `Node` of a given type; C# gets typed `GetChildren<T>()` and `FindChildren<T>()`. In code: `scene/main/node.*`, `modules/mono/`. Wiki: [`Children-of-a-Type`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Children-of-a-Type).

**Class reference**: the XML description of a class in `doc/classes/<Class>.xml` (written as `--doctool` writes it; module classes in `modules/<module>/doc_classes/`) and one wiki page `Class-<Class>` per class. Mandatory for every new or changed class.

**Concept issue**: an issue that ends with a proposal and a "Decision" comment instead of code; decisions are collected on the wiki page `Design-Decisions` (for example #4, #6, #13, #14, #31).

**CSV**: tabular text format in core with the same `parse()` / `stringify()` / `serialize()` shape as the other text formats. In code: `core/io/csv_format.*`. Wiki: [`CSV`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/CSV).
**CSVReader**: reads a large CSV file row by row from `FileAccess` (bounded memory, `seek_row()` with a sparse row index for paging, `count_rows()`, `read_record()`); `CSV` keeps every cell in memory. In code: `core/io/csv_reader.*`. Issues: #439 (concept #421). Wiki: [`Class-CSVReader`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Class-CSVReader).

### D

**Dataset dock** (#436, #438, concept #420): bottom dock `DatasetEditor` for tabular data files: data CSVs (typed cells and issues from a `DataSchema`) and table-shaped JSON/YAML/TOML (arrays of dictionaries at the root or under a top-level key), INI (sections as rows) and XML (children of the root with one tag, attributes as columns). Columns are the keys of all rows; each row writes only its own keys. Side bar of open files with one undo history per file (right-click menu, unsaved files ask before closing), paging (500 rows), menus File (Save, Open as Text, Show in FileSystem, Close), Values (Add/Insert/Delete Rows, Insert/Remove Column, Undo/Redo) and Table (Export as CSV/JSON), kept in sync with the text editor. Opens on double-click (data CSVs, at least two records sharing a key, at least two XML elements; not INI, not above 4 MiB) and with "Open in Dataset Dock" (Inspector, FileSystem context menu). Editor only, no API. In code: `editor/data/dataset_editor.*`. Wiki: [`Dataset-Dock`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Dataset-Dock).

**Data file inspector**: the Inspector view of `TextDataFormat` and `JSON` resources, one inspector plugin per format (#435) on the shared `DataFileInspectorView` (summary with parse status and schema issues, Validate, one button per dock that edits the file: Open in INI Dock / Open in Localization Table Dock / Open in Dataset Dock, the last with the file's tables in its tooltip; "Open as Text" is in the FileSystem context menu since #436). Per format: CSV preview table (first 100 rows, column titles show the schema field), INI tree of sections (keys without a section under "(no section)"), XML element tree, JSON value tree, YAML value tree with one row per document, TOML tree with "Table" / "Array of Tables". Trees have a Key | Type | Value layout filled on expand, with search. Hides the default `data`/`header` editors ("Raw Properties" shows them). Editor only, no API. In code: `editor/inspector/data_file_inspector_plugin.*` (shared view, `DataFileTreeAdapter` with the pure logic, JSON plugin), `editor/inspector/{csv,ini,xml}_inspector_plugin.*`, `modules/{yaml,toml}/editor/*_inspector_plugin.*`. Issues: #361, #435. Wiki: [`361-feature-data-file-inspector`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/361-feature-data-file-inspector).

**Data schema** (`DataSchema`, `DataField`, `DataValidation`, `DataValidationOptions`): format-independent description of the keys, columns and attributes of a data file (CSV, INI, JSON, TOML, YAML, XML). `DataField` is shaped like `PropertyInfo` (type, hint, hint string) plus required, unique, allow empty, default value, pattern and nested schemas; `DataSchema.validate()` and `TextDataFormat.validate()` return a `DataValidation` with every issue and its field, path, row, column and line. In code: `core/io/data_schema.*`, `core/io/data_field.*`, `core/io/data_validation.*`. Issues: #277 (decision #270). Wiki: [`277-feature-data-schema`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/277-feature-data-schema), [`Class-DataSchema`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Class-DataSchema).

**Decision (comment)**: open questions of an issue are decided by the orchestrator and posted as a comment headed "Decision". See `.agents/project.md`.

**Design decisions**: wiki page with the concept decisions and their follow-up work. Wiki: [`Design-Decisions`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Design-Decisions).

**Dialogue graph** (`DialogueLineNode`, `DialogueChoiceNode`, `DialogueOption`): a `FlowGraph` with line and choice nodes. Lines and choices wait; the game's own UI shows them on `node_waiting` and continues with `advance()` or `choose()`. Texts are translated with `tr()` (sentences or CSV keys); options have `Expression` conditions over the blackboard and `once`. Texts reach POT generation through the generic `ResourceTranslationParserPlugin` (`tres`, `res`, `mmd`, any resource with `get_translatable_strings()`). No UI node. In code: `modules/flow_graph/dialogue/`, `editor/translations/resource_translation_parser_plugin.*`. Issues: #259. Wiki: [`259-feature-flow-graph-dialogue`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/259-feature-flow-graph-dialogue). Not to confuse with `AcceptDialog`/`ConfirmationDialog` (editor and UI windows).

**Recursive directory listing**: `DirAccess` lists all files or folders below a path in one C++ call, optionally filtered by extension. In code: `core/io/dir_access.*`. Wiki: [`Recursive-Directory-Listing`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Recursive-Directory-Listing).

### E

**EngineSettings** / **EngineSettingsServer**: settings domain for engine-wide options. In code: `servers/settings/engine_settings*.*`. Wiki: [`Engine-Settings`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Engine-Settings).

**`exec://`**: path prefix for the folder of the running executable (in the editor and in games started from it: the project folder). See **Path prefix**. Not to confuse with `res://` (project resources, read-only in exports) and `user://` (writable user data).

### F

**Feature branch**: branch `<nn>-feature|refactoring|bug|concept-<name>` from `truely-godot-engine`, with the issue number (at least two digits) as prefix, for example `03-feature-path-prefix-server`. Squash-merged into `truely-godot-engine` and **never deleted**. See `truely/README.md` and `truely/FEATURE-WORKFLOW.md` (2.1).

**File manifest** (`FilesManifest`): data description of a set of files (folders, extensions, single files, a type) that `ResourceLoader` lists or loads in one call, in the editor, in exports and in packs. `FilesManifestServer` holds named manifests, `FilesManifestValidation` reports problems. Load order: folders first (list order, files of a folder sorted by path), then files (list order); `*` in a folder path matches one folder level. In code: `core/io/files_manifest*.*`, Inspector: `editor/inspector/files_manifest_editor_plugin.*`. Issues: #8, #354. Wiki: [`File-Manifests`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/File-Manifests).

**FlowGraph**: resource that holds `FlowNode`s under ids the graph owns (never reused) and the connections between their named ports (`FlowPort`, `FlowConnection`), plus `FlowFrame`s and declared `FlowVariable`s; `validate()` returns a `FlowGraphValidation`. Storage is hidden in the inspector and edited through methods. Base of quests, dialogs and other node graphs; the module can be disabled (`module_flow_graph_enabled=no`). In code: `modules/flow_graph/`. Issues: #253, #254, #255. Wiki: [`255-feature-flow-graph`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/255-feature-flow-graph), [`Class-FlowGraph`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Class-FlowGraph). Not to confuse with `GraphEdit`/`GraphNode` (UI controls) or `FlowContainer`.

**FlowGraphMermaid**: reads and writes a `FlowGraph` as a Mermaid flowchart (`.mmd`); structure as plain Mermaid, types and properties in `%% flow:` comment lines (lossless); hand-written flowcharts load with generic nodes. `.mmd` loads/saves as `FlowGraph`; exports convert text graphs to binary `.res` (`flow_graph/export/convert_text_to_binary`). In code: `modules/flow_graph/flow_graph_mermaid.*`, `flow_graph_editor_formats.*`. Issues: #258. Wiki: [`258-feature-flow-graph-formats`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/258-feature-flow-graph-formats), [`Class-FlowGraphMermaid`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Class-FlowGraphMermaid).
**FlowGraphPlayback**: walks a `FlowGraph` like a state machine: current node, exits and choices (`FlowExit`), travel, data pulls, subgraphs, variables in a `FlowBlackboard`, save and restore through `FlowGraphState`. `FlowGraphPlayer` is the thin node that plays it in the scene tree and processes only while a node waits. Node types implement `_enter()`, `_choose_exit()`, `_evaluate_output()`, `_process_waiting()`. In code: `modules/flow_graph/flow_graph_playback.*`, `flow_graph_player.*`. Issues: #256. Wiki: [`256-feature-flow-graph-playback`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/256-feature-flow-graph-playback), [`Class-FlowGraphPlayback`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Class-FlowGraphPlayback). Not to confuse with `AnimationNodeStateMachinePlayback`.

**FlowNode**: base resource of the node types of a `FlowGraph`, in C++ (`FlowStartNode`, `FlowEndNode`, `FlowBranchNode`, `FlowExpressionNode`, `FlowGetVariableNode`, `FlowSetVariableNode`, `FlowEmitEventNode`, `FlowSubgraphNode`, `FlowWaitNode`) or as GDScript/C# scripts that override `_get_input_ports()`/`_get_output_ports()`. Ports are cached; `notify_ports_changed()` refreshes them. In code: `modules/flow_graph/flow_node.*`, `flow_nodes.*`. Issues: #255. Wiki: [`Class-FlowNode`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Class-FlowNode).

### G

**Glue** (C# glue): C# wrapper code generated from the built engine with `--generate-mono-glue modules/mono/glue`. It must be regenerated after every change of bound classes, otherwise new classes are missing in C#. Singletons get a static `Foo` and an instance wrapper `FooInstance`. In code: `modules/mono/`. See `truely/FEATURE-WORKFLOW.md` (section 3).

**Graphics preset** (`GraphicsPreset`, `GraphicsPresetSettings`, `GraphicsPresetSettingsServer`): a named bundle of render quality, shadow, texture, effect and window values applied in one call. Formerly `VideoPreset` (#243). In code: `servers/settings/graphics_preset*.*`. Wiki: [`Graphics-Presets`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Graphics-Presets). Not to confuse with `VideoStreamPlayer` (video playback).

### H

**HTTPRequestTarget** / **HTTPResponse**: `HTTPRequestTarget` is a `Resource` with URL, method, headers and body of a request, editable in the inspector; `HTTPRequest` takes it and returns an `HTTPResponse`. In code: `scene/resources/http_request_target.*`, `scene/main/http_response.*`, `editor/inspector/http_request_target_editor_plugin.*`. Wiki: [`HTTP-Requests`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/HTTP-Requests).

### I

**INI**: INI text format (Variant syntax plus a plain mode). In code: `core/io/ini_format.*`. Wiki: [`INI`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/INI).

**InputAction** / **InputActions** / **InputActionRebinder**: resources and helper for built-in actions and player key rebinding. In code: `core/input/input_action*.*`, `core/input/builtin_input_actions.*`, `servers/settings/input_action_rebinder.*`. Wiki: [`Input-Settings`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Input-Settings).

**InputIconServer** / **InputIconSet**: pick the button prompt icon (key, mouse, gamepad family) for the player's current device. In code: `scene/main/input_icon_server.*`, `scene/resources/input_icon_set.*`. Wiki: [`Input-Icons`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Input-Icons).

**InputMapSettingsServer**: settings domain that saves and applies rebound `InputMap` events (records in `input_map_settings_records.h`). In code: `servers/settings/input_map_settings_*.*`. Wiki: [`Input-Map-Settings`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Input-Map-Settings).

**InputSettings** / **InputSettingsServer**: settings domain for input options. In code: `servers/settings/input_settings*.*`. Wiki: [`Input-Settings`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Input-Settings).

### L

**LanguageSettings** / **LanguageSettingsServer**: settings domain for the game's locale and the locale channels `interface`, `audio`, `subtitles` (empty = same as language, #357). In code: `servers/settings/language_settings*.*`. Wiki: [`Language-Settings`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Language-Settings).

**ListSettingsServer**: base for settings domains that hold a list of records (for example the TTS personas). In code: `servers/settings/list_settings_server.*`.

**Load result** (`ResourceLoadResult`, `ResourceSaveResult`): return value with error code and message for loading and saving; C# `TryLoad<T>`. In code: `core/io/resource_result.*`. Wiki: [`Load-Results`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Load-Results).

**Loader index**: lookup of `ResourceFormatLoader` by file extension through a copy-on-write snapshot; the old limit of 64 loaders and savers is gone. In code: `core/io/resource_loader.*`. Issues: #2, #6. Wiki: [`Loader-Index`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Loader-Index), [`Resource-Format-Limits`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Resource-Format-Limits).

**Locale channel**: a part of the game with its own locale (`interface`, `audio`, `subtitles`, custom), set with `TranslationServer.set_locale_for()`; empty = follows the general locale. A channel is a `TranslationDomain` (`interface` = main domain, others = domain of their name, `audio` none); nodes pick one with `Node.translation_domain`. Signal `TranslationServer.locale_changed(channel, locale, previous_locale)`. The player's choice per channel (`interface`, `audio`, `subtitles`, empty = same as language) is stored by `LanguageSettingsServer` (`set_locale_for()`, `get_available_locales_for()`). In code: `core/string/translation_server.*`, `servers/settings/language_settings_server.*`. Issue: #357.

**LocaleOptionButton**: language menu (an `OptionButton`) that lists the locales of the project (`LanguageSettingsServer.get_available_locales_for()`) under their native names; selecting sets the locale of its `target` channel and the entry follows `locale_changed`. In code: `scene/gui/locale_option_button.*`. Issue: #414. Wiki: [`414-feature-project-locales`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/414-feature-project-locales), [`Class-LocaleOptionButton`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Class-LocaleOptionButton).

**LocalizationCatalog** (`TextLocalizationCatalog`, `ResourceLocalizationCatalog`, `.lcat`): table of localized strings, one row per key (with context) and one column per locale; a column is one UTF-8 buffer plus `uint32` offsets (data-oriented, ~4 B per message besides the text). Text catalogs add plural forms and a plural rule per locale, resource catalogs map resource paths to localized paths with an expected type. Formats: CSV with the importer's rules, JSON/YAML/TOML/INI (`key: {locale: text}`), XML, and the binary `.lcat` that loads one locale at a time. Converts from/to `Translation` and `translation_remaps`. Each catalog has a locale `channel` (text: `interface`; resource: by key type). Translator notes: other `_` columns/fields (`_notes`, `_max_length`) per key (`get_note()`), kept in text formats and `.tres`, never in `.lcat`, skipped when `ResourceLoader` loads a catalog outside the editor. Text formats load through `ResourceLoader` with a catalog type hint; plural rules are compiled once per rule text (`get_plural_rules()`). One key as a Dictionary in the JSON shape: `get_entry()`/`set_entry()` (editor undo/redo); checks: `validate()` (missing translations, duplicate keys of the loaded text, invalid locales; lines for text files); gettext: `TextLocalizationCatalog.to_po()`; text I/O takes `SerializerOptions` (CSV delimiter detected otherwise). In code: `core/string/localization_catalog.*`. Issues: #339, #341, #346, #357. Wiki: [`341-feature-localization-catalog`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/341-feature-localization-catalog). Not to confuse with `Translation` (one locale of one file) or `TranslationServer`.
**Localization editor** (#346): editor tools for `LocalizationCatalog`s. The Localization Table dock (`CSVTableEditor`, the former CSV Table dock; also translation CSVs: imported as translation, or every column after the first a locale, `_note` or `?context`/`?plural`) has a catalog mode (columns = entry fields: key, context, plural key/type, locales, `_` notes; plural forms as child rows; undo/redo through `set_entry()`); the inspector lists missing keys per locale and saves a POT; FileSystem "Use as Text/Resource Localization Catalog" adds data files to `catalog_manifests` (CSV switched to "Keep File"); Project > Tools > "Convert Project Translations to Catalogs..." moves `translations`/`translation_remaps`; the export plugin writes text catalogs of the manifests as `.lcat` (setting `internationalization/localization/export/convert_text_to_binary`). In code: `editor/data/localization_catalog_editor_plugin.*`, `editor/data/csv_table_editor.*`. Wiki: [`346-feature-localization-editor`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/346-feature-localization-editor).

**LocalizedText**: resource with a translation `key`, `context`, `args`, `count_argument` (plural from a value such as `enemy.count`), `channel` and `refresh_mode`; `get_text()` returns the translated text with its `{name}` placeholders filled. Bound to node properties through the one metadata key `localized_text` (a `LocalizedText` for `text`, or a dictionary property → `LocalizedText`; inspector: Add Metadata, or `bind()`), it refreshes the property only when its locale channel, a used placeholder value, a catalog or itself changes (one shared registry, no signal connection per binding). In code: `scene/resources/localized_text.*`. Issues: #339 (decision), #345. Wiki: [`345-feature-localized-text`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/345-feature-localized-text), [`Class-LocalizedText`](https://github.com/TruelyMostWanted/truelymostwanted-godot-engine/wiki/Class-LocalizedText). Not to confuse with Godot's `auto_translate` (plain keys only).

### M
